Cloudflare ile birlikte

  • Yalnız Cloudflare kuralı (WAF → özel kural "IP adresi listede değilse engelle") yalnız alan adı yolunu korur; sunucunun doğrudan IP adresi (IP:18443) açık kalır.
  • Bu sayfadaki liste iki yolu da ve API'yi korur; Cloudflare'a gerek kalmadan çalışır.
  • İkisini birlikte kullanırsanız Cloudflare kötü trafiği daha sunucuya gelmeden keser; bu liste de doğrudan IP yolunu kapatır. Önerilen: bu liste (gerekirse ek olarak Cloudflare).

Sunucu ziyaretçi adresini alan adı yolunda Cloudflare'ın gönderdiği gerçek adresten, IP yolunda doğrudan bağlantıdan alır (TRUST_PROXY=1 ile). Ayarınız: TRUST_PROXY={{ '1' if trust_proxy else '0' }}{% if not trust_proxy %} — sunucu nginx arkasındaysa 1 olmalı{% endif %}.
