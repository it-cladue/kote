# Entegrasyon kaynakları

Gyazo isteğe bağlı görsel yüklemesi resmi Image API belgesine göre multipart POST `https://upload.gyazo.com/api/upload` uç noktasına yapılır; alanlar `access_token` ve filename içeren binary `imagedata`dır. Dönen alanlar image_id, permalink_url, url. Kaynak: https://gyazo.com/api/docs/image (17 Ekim 2026’da okundu). Varsayılan `access_policy=anyone`: bağlantıyı bilen görüntüyü görebilir; bot ve panel dönüşüm düğmesi bunu açıkça belirtmelidir. `only_me` sadece yükleyen Gyazo hesabı için görüntülenebilir; ortak kanıt linki kullanımına varsayılan yapılmaz. Yerel özel dosya her durumda korunur, zorunlu Gyazo bağımlılığı oluşmaz.

Telegram Bot API resmi kök belgesi: https://core.telegram.org/bots/api. Türler yeni ayrı Markdown sayfalarına taşınmıştır; InlineKeyboardButton tanımı: https://core.telegram.org/bots/api/types/inlinekeyboardbutton.md. Telegram mesajlarında keyfi HTML renk stili kullanılmaz; buton türünün izin verdiği sınırlı stiller ve renkli proje işaretleri kullanılacaktır. Botlar arası file_id taşınamaz; yeni test botu eski botun geçmiş dosyalarını sırf tokenıyla indiremez. Mevcut `telegram_gorseller` yerel arşivi bu nedenle ayrı taşınır.
